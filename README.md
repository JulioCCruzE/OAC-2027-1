# Organización y Arquitectura de Computadoras 2027-1 (OAC-2027-1)

Este repositorio alberga las tareas a evaluar (denominados «laboratorios»)
para la materia de Organización y Argquitectura de Computadoras en el semestre 2027-1.

Cada laboratorio esta conformado por una serie de ejercicos que se deberan contestar y
mandar a calificar para ir registrando su progreso.

Se iran añadiendo nuevos laboratorios a medida que avancemos en el curso.
